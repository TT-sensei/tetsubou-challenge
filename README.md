# 鉄棒チャレンジ

小学校体育・器械運動（鉄棒）の児童向け教材ページです。自分に合った技を選び、技のポイントと練習方法を知り、公式のお手本動画・資料へのリンクから学びます。

## 構成

- トップ：安全のやくそく（常時表示）、4つの入り口カード、学習の記録、資料室
- カテゴリ：鉄棒に慣れよう／回転・支持の基本／回転技に挑戦／技を組み合わせよう
- 技ページ（全20技＋活動2件）：できるポイント、できないときの練習方法、公式動画・資料へのリンク、つぎに挑戦できる技、練習チェック（「できた！」と練習回数、端末内に保存）
- 連続わざをつくろう：のぼり方・なかの技・おり方を1つずつ選んで、発表用の連続わざを作れる（発表画面つき）

## 方針

- 動画・資料は公式ページへの外部リンクのみ。自前サーバーへの再掲載はしない
- 説明文はTT-senseiのオリジナルの短い文章
- 難しい技（回転技など）には「先生や大人の補助のもとで行う」注意を明示。難易度とは別に、足ぬき回り・ダンゴ虫・地球回り・こうもりには「先生に見てもらってから」の見守り注意を表示。補助の表現は「先生に確認した方法で」を基本に統一
- データ保存はlocalStorage（キー：tetsubouChallenge.v1／tetsubouChallenge.settings.v1／tetsubouChallenge.routine.v1）
- ふりがな（固定読み辞書によるルビ表示。読みが文脈で変わる漢字には付けない）は初期表示ONで、ヘッダーでON/OFFでき、設定は端末に保存される
- 外部API・外部フォント・外部CDNは使わない（ナビキャラの表情画像と効果音はTT-senseiの共通基盤から読み込む）
